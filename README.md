# X-ray Detector Calibration Using Machine Learning

This project develops a machine learning pipeline for calibrating X-ray detectors using noisy threshold-scan signals.

## Project Overview
- Feature engineering from threshold-scan curves
- Gaussian smoothing
- Threshold crossing detection
- Gradient and curvature features
- Histogram-based Gradient Boosting Regressor
- Residual learning strategy

## Technologies
- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
This project was completed as part of the Datacamp 2025 challenge.
